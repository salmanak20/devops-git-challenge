## 2. Reflection Questions

### Q1: Difference between Git and GitHub

Git is a distributed version control system used to track
changes in project files. It allows developers to manage
commits and branches locally. GitHub is an online platform
used to host Git repositories. GitHub also provides features
like Pull Requests and team collaboration.

### Q2: Explain Working Directory, Staging Area, and Local Repository

The Working Directory contains the project files that we
create and modify. The Staging Area holds changes that are
ready to be committed using git add. The Local Repository
stores the committed changes and their history. These three
stages help developers manage changes in an organized way.

### Q3: Difference between git stash pop and git stash apply

Both commands restore changes saved using git stash.
The git stash pop command restores the changes and removes
the stash entry when successfully applied. The git stash
apply command restores changes but keeps the stash entry.
I can use apply to reuse a stash and pop when it is no
longer needed.

### Q4: Difference between git fetch and git pull

The git fetch command downloads updates from the remote
repository without merging them into the current branch.
The git pull command downloads changes and integrates
them into the current branch. Git fetch allows developers
to review changes before merging. Git pull is useful when
we want to update our local branch directly.
